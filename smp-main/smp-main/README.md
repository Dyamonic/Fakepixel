### Fakepixel smp core

- required:
- paper 1.21.11
- abelix api and core
- proxy-velocity
- smp-1.0
- smpmobengine
- MariaDB - holds all the data
- Redis - ghost engine

## features
- dungeons.
- fishing system.
- cooking system.
- combat system.
- enchantment system.
- randomize stats/rarity for weapons/armor/tools.
- adventure guild/ranks/quests
- smp level players can level up from 1 to 10k with different colors per 100 - 1k to 10k each level has its own icon next to the level number and it'll also give the player stats upgrades for health/defense/mana.
- player create able guilds.
- guilds can claim land.
- guild wars/allies.
- exchange from gold to coins
- gold store for cosmetics, account upgrades, battlepass levels.
- battlepass.
- playtime rewards.
- skill system 
- jobs system
- discoverable zones
- waypoints players can warp to different zones or there own sethomes, dungeons, rtp or back to spawn.
- calendar to view upcoming events. its like how skyblock has events every few Minecraft days.
- Storage system but as enderchests with slots as big as 54 and more pages can be bought at the goldstore.
- bank system for depositing your coins or withdrawing them and you can upgrade its capacity, interest rate, Transaction History.
- Event Shop part take in a event to gain event tokens then use those tokens to buy items from the event shop.
- & more.
